Ticketing System
================

The Ticketing System is a deliberately small FastAPI, NiceGUI, and DuckDB
application used in debugging workshops. These pages describe how to run the
project, how its components fit together, and the Python interfaces available
to tests and application adapters.

The current branch can contain intentional defects. Treat :doc:`SPEC` as the
normative product contract and the generated :doc:`api_reference` as a view of
the code that is currently present.
